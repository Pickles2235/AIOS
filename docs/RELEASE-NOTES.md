# V1 engineering candidate

This completion mission preserves the canonical repository Knowledge IR, bounded
deterministic retrieval, immutable generations and honest coverage. The package
bundles the production UI, structural extractors and local Nomic embedding assets.
Per-user daemon lifecycle and checksummed ZIP installation are under verification.

Supported product: macOS Apple Silicon. Linux builds are developer smoke only.
Native launchd/login, installed upgrades, resource signals, namespace resolution,
GPU rendering and full assembled acceptance need actual native evidence. Missing
mandatory gates block candidate readiness. Signing/notarization is pending and is
not a first-candidate prerequisite. The stakeholder's release decision is pending.

No runtime LLM connection, generative agent, telemetry exporter or public release
is added. Current limitations and unrun native checks remain recorded in the
completion plans and evidence. Future owner milestones replace incomplete feature
probes with tested outcome/fault assertions before final acceptance.
